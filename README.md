## 同样叫“专线”，报价为什么能差几十倍？

方向、带宽、线路类型，这三个变量决定了你看到的报价是800还是80000，其中方向差价最夸张。

运营商国际专线（IPLC类）2025年底参考月租，不含初装费：

| 目的方向 | 10Mbps | 100Mbps | 1Gbps |
| --- | --- | --- | --- |
| 香港/台湾 | 约8000-12000元 | 约3-5万元 | 约20-30万元 |
| 日韩/新加坡 | 约1.2-1.8万元 | 约5-8万元 | 约30-50万元 |
| 欧美/澳洲 | 约2-3万元 | 约8-15万元 | 约60-100万元以上 |

逻辑很直白：香港离得近、出口资源多，所以最便宜；欧美要跨洋，链路成本高，价格直接翻两三倍。即便是运营商直签，香港方向2-10M的入门档也在5000-8000元/月，欧美方向要1.5-2.5万。

线路类型是另一个大头。传统IPLC/IEPL是点对点物理专线，稳但贵；SD-WAN走国际优化路由，成本能压到传统专线的四到六成，代价是SLA一般只有99.5%（传统IPLC多为99.99%），丢包和延迟略高。日常邮件、ERP、客户沟通，99.5%完全够用；金融级传输或大规模跨境视频会议，才需要为那0.5%多付几倍的钱。

## 运营商直签还是第三方SD-WAN？先看差价再决定

预算有限的中小企业，第三方SD-WAN通常就够；对稳定性要求极高的大团队，再考虑运营商直签。拿两个已知的报价对比：联通SD-WAN优化专线20M、预付一年，月租5280元起；第三方服务商的香港5M，月付约800-900元。前者带宽更大，月租也高出好几倍。

第三方便宜有两个原因。一是带宽来源：三大运营商一般不直接对接中小企业，跨境带宽多经授权合作方转售，第三方拿的是批发价；二是技术路线：SD-WAN用智能路由替代了昂贵的点对点物理链路。市面上不少这类方案的交付形式是在办公室放一台CPE设备做分流，有的出于合规考虑只放行Office 365、Amazon这类办公应用的白名单，额外需求要单独申请。签约前把这条问清楚，免得业务跑起来才发现某类网站走不通。

省钱的做法基本就这几条：

1. 方向优先香港，比欧美方向便宜60%-70%，访问谷歌、邮箱、ERP，香港线路基本能覆盖；
2. 用SD-WAN替代IPLC，成本降到传统专线的40%-60%；
3. 低带宽（2-5M）起步，按业务量扩容，小带宽单价更低；
4. 找运营商授权的第三方服务商，能拿到批发价，常免安装调测费；
5. 预付1年享8-9折，3年约7-8折；
6. 优先选免一次性接入费的套餐，仅这一项就能省5000-20000元。

## 除了月租，还要预留哪些钱？

最容易漏算的是初装费。运营商直签的IPLC开通涉及跨境部署和调测，一次性费用通常在5000元到2万元之间，签约前一定问清是否包含。第三方方案不少提供“免初装”套餐，但也有按设备或调试另行收费的。

另外两笔潜在支出：扩容费，业务量上来后升级带宽，有的按差价补，有的重新签合同，规则各不相同；设备费，CPE设备有的随套餐提供，有的收押金或租金。

签约前建议把三个问题问死：SLA承诺多少？初装费、设备费怎么收？后续扩容怎么计价？这三个答案基本能筛掉不靠谱的渠道。

## 办理流程和需要准备的材料

流程本身不复杂：找持牌服务商提交企业资质和用途说明，备案审核通过后签约部署，验收合格就开通。按步骤走是这样五步：

1. 明确跨境用途（办公、ERP、云访问等）、带宽和目标国家/地区，选择持牌服务商；
2. 提交企业资质和用途说明，由服务商协助向通信管理部门备案；
3. 等待形式审查与实质审核，必要时配合现场核查；
4. 审核通过后签约付款，服务商部署线路、跨境调测；
5. 测试网络质量，验收通过正式开通，留存验收报告。

材料围绕“证明你是正规企业 + 说明用途”准备：加盖公章的营业执照副本复印件、法定代表人身份证复印件、经办人身份证及授权委托书、企业章程与股权结构、跨境网络用途说明（写清用途、目标国家/地区、使用的系统）、网络拓扑图与技术方案、数据安全与保密管理制度、承诺不用于违规用途的书面声明，以及服务商提供的申请表和办公场所证明（租赁合同或产权证明）。

## 外贸专线收费常见问题

### 5M带宽够用吗？

看用途和并发人数。网页浏览、邮件、ERP、WhatsApp这类轻量办公，5M起步是主流选择；视频会议密集或经常传大文件，直接往10M以上配，反正后续可以扩容。

### 月付和年付能差多少？

市场行情是年付8-9折、3年约7-8折。以第三方香港5M为例，年付折合每月约817元，低于按月支付的上限，周期越长折扣越深。

### 没有营业执照能办吗？

办不了。营业执照是必备材料，专线以企业名义申请并备案，个人身份走不通这套流程。

### 报价便宜的和贵的，差在哪？

主要差在线路类型和SLA：99.5%的SD-WAN和99.99%的IPLC是两个价位，方向和带宽再往上叠。报价差异大不代表有人乱开价，先对齐配置再比价。
